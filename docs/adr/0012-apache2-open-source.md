# ADR 0012 — Apache License 2.0 for original source
**Status:** proposed · **Date:** 2026-11-04

## Decision (proposed)
Apache License 2.0 for original source.

## Why
Permissive open source supports portfolio scrutiny and potential independent commercial hosting.

## Tradeoff
Any third-party code and contributions still need license/attribution review.

## Acceptance / reconsideration
No proprietary component copied without explicit authorization.

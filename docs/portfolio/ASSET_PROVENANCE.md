## Reproduction and boundaries

To independently reproduce, start the demo with [the local Windows launcher](../../scripts/windows-start-slice2.ps1) and follow the [recording walkthrough](DEMO_STORYBOARD.md). The integrated browser test source is [`scripts/browser-slice2.mjs`](../../scripts/browser-slice2.mjs); each image is captured from the same synthetic session after explicit assertions. The demo uses a fixture classifier and a local synthetic CRM, **not** real AI inference, an external business CRM, or a public deployment.

The screenshot of the synthetic CRM was originally missing because an earlier browser test navigated to History before saving its image; this was corrected in test-only commit `12211b15...`, and its new CI passed. The original mobile CRM screenshot demonstrates a *separate empty guest session*, not a CRM write, so it is intentionally omitted from the three featured images.

Images include a short-lived pseudonymous local demo workspace code generated by the test. They contain no intentionally supplied real customer information or credentials. Review screenshots before reusing them in external marketing.
